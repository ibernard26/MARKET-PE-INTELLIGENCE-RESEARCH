# Geopolitical intelligence staging (research only)

| File | Role |
|---|---|
| `evidence_ledger.jsonl` | Append-only evidence ledger (`src/geo_intel/store.py`). **Empty at introduction: no real-world event has been staged or verified.** |
| `exposure_links.jsonl` | Reviewed event→deal research links (`src/geo_intel/exposure.py`). Empty. |
| `fs_v2_geo_candidates_DRAFT.json` | Design-only draft of possible future fs_v2 geopolitical fields. Not active. |
| `report/` | Read-only report generated by `python -m src.geo_intel.reporting`. |

Nothing here enters the canonical SQLite store, fs_v1 or any training/decision
path. Grok/X briefs are staged as untrusted `ai_brief` records and can never
verify an event. See `docs/GEOPOLITICAL_INTELLIGENCE_PLAN.md`.

Pilots / dry runs of relayed feeds (e.g. Todd's `events-YYYY-MM-DD.jsonl`) must use a
staging ledger OUTSIDE this directory, e.g.
`python -m src.geo_intel.todd_adapter FEED --ledger /workspace/geo_staging/<date>/ledger.jsonl`.
