# first_walkforward_v1 — execution path (replication runner)

Built at Isaiah's direction on 2026-10-21. **Code only in the commit that adds
this file: nothing executed, `execution_authorized` still `false`.**

Any run of this code is a **REPLICATION of results already public in PR #23**
(opened 2026-09-26). The test windows are not blind, so a run is not a fresh
out-of-sample test. Windows 1 and 2 have test n = 8 and 3 (per the frozen
`plan.json`), below the protocol's `MIN_SAMPLE_N = 20`. Single walk-forward,
unvalidated, AI-authored (not independent human review). Research only; no
trading, alpha or P&L claim.

## Entry point

```bash
cd pe-tracker
SEC_USER_AGENT="<approved contact; env only, never committed>" \
python -m src.model.walkforward_execute --authorize "AUTHORIZE FIRST REAL WALKFORWARD"
```

No tuning knobs: hyperparameters, cutoffs (2021-06-30 / 2023-06-30 /
2025-06-30), horizon (2026-09-26), threshold rule and metrics are read from the
locked `protocol.json` and locked code. Only `--out-dir` is configurable.

## Fail-closed gates (before any fit)

1. `protocol.json → execution_authorized` is `true` (`experiment_prep.refuse_execution`).
2. `--authorize` equals `authorization_command_required` exactly.
3. `protocol.json → authorization_record` has `approver` and `authorized_at`.
4. `status != "EXECUTED"`; output `results.json` must not already exist (execute once).
5. No calibration / tuning / random k-fold; `assert_locked_contract` passes.
6. `SEC_USER_AGENT` set; tracked files clean (`git status`).
7. The plan regenerated by the frozen prep code from the live store must equal
   the committed `plan.json` exactly (cohort identity, counts, row identities,
   train and test dataset fingerprints).

Per window the sequence is delegated unchanged to `validation.fit_and_score`
(fit → t* on training in-sample predictions → freeze → grade untouched test
window, plus constant and spread-only baselines). `register_model` writes to the
ephemeral in-memory store only.
