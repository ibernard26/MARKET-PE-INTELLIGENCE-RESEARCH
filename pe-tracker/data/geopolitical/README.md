| File | Role |
|---|---|
| `evidence_ledger.jsonl` | Append-only evidence ledger (`src/geo_intel/store.py`). Loaded from Todd's daily feed via `python -m src.geo_intel.todd_adapter`. All rows enter as UNCONFIRMED; none are features. |
| `exposure_links.jsonl` | Reviewed event→deal research links (`src/geo_intel/exposure.py`). Empty. |
| `fs_v2_geo_candidates_DRAFT.json` | Design-only draft of possible future fs_v2 geopolitical fields. Not active. |
| `report/` | Read-only report generated by `python -m src.geo_intel.reporting`. |

Nothing here enters the canonical SQLite store, fs_v1 or any training/decision
path. Grok/X briefs and Todd-relayed items are staged as untrusted
(`ai_brief` / `social_post` / `other`) with `retrieved_by_reviewer=false` and
can never verify an event by themselves. See `docs/GEOPOLITICAL_INTELLIGENCE_PLAN.md`
and `docs/V1_READINESS_REPORT.md`.
